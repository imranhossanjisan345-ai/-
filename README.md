# আমার এলাকা — HTML/CSS/JavaScript ওয়েবসাইট

## ফাইলগুলো
- `index.html` — ওয়েবসাইটের কাঠামো
- `style.css` — ডিজাইন ও মোবাইল-ফ্রেন্ডলি লেআউট
- `app.js` — বিভাগ/জেলার তালিকা, সার্চ, ফিল্টার ও বিস্তারিত পপ-আপ
- `areas.json` — পরবর্তীতে যাচাই করা এলাকার তথ্য রাখার নমুনা কাঠামো

## কম্পিউটারে পরীক্ষা
সব ফাইল একই ফোল্ডারে রাখুন এবং `index.html` ব্রাউজারে খুলুন। Google Fonts-এর জন্য ইন্টারনেট থাকলে বাংলা ফন্ট ভালো দেখাবে; না থাকলেও fallback font কাজ করবে।

## GitHub Pages-এ বিনামূল্যে প্রকাশ
1. GitHub-এ অ্যাকাউন্ট তৈরি/লগইন করুন।
2. নতুন repository তৈরি করুন (যেমন `amar-elaka`)।
3. এই ফোল্ডারের ফাইলগুলো repository-তে upload করুন। `index.html` অবশ্যই মূল ফোল্ডারে থাকতে হবে।
4. Repository → Settings → Pages-এ যান।
5. Build and deployment-এ `Deploy from a branch` নির্বাচন করুন, branch `main`, folder `/ (root)` নির্বাচন করে Save করুন।
6. প্রকাশের URL-টি Pages সেটিংসে দেখাবে। প্রকাশ হতে কিছু সময় লাগতে পারে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি একটি কার্যকর frontend starter template, বাংলাদেশের সব উপজেলা, ইউনিয়ন, পৌরসভা ও গ্রামের পূর্ণাঙ্গ ডেটাবেস নয়। এখানে ৮টি বিভাগের জেলা তালিকা এবং কয়েকটি নমুনা এলাকার বিস্তারিত আছে। গ্রাম/ইউনিয়নের পূর্ণ তালিকা প্রকাশের আগে নির্ভরযোগ্য সরকারি উৎস থেকে সংগ্রহ, যাচাই ও ডেটাতে যোগ করতে হবে। জনসংখ্যা, আয়তন বা ইতিহাসের কোনো তথ্য উৎস ও সাল ছাড়া প্রকাশ করবেন না।

## ইমেইল বদলানো
`index.html`-এ `info@example.com` খুঁজে নিজের প্রকাশ্য যোগাযোগের ইমেইল বসান।

## পরবর্তী উন্নয়ন
- `areas.json`-এ যাচাই করা এলাকার তথ্য যোগ করা
- জেলা → উপজেলা → ইউনিয়ন → গ্রাম hierarchy
- প্রতিটি সংখ্যাগত তথ্যের পাশে উৎস ও তথ্যের সাল
- মানচিত্র, ছবি, তথ্য সংশোধনের ফর্ম
- বড় ডেটার জন্য আলাদা JSON/ডেটাবেস ও উন্নত সার্চ
